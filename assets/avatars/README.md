# EVA Foods demo avatars

These 100 PNG avatars were generated and downloaded locally from DiceBear's
official Open Peeps avatar API, using distinct stable seeds `eva-foods-001`
through `eva-foods-100` at 128px. The Open Peeps style is listed as CC0 1.0 by
DiceBear. No network request is made by the app to display these files.

- Generator/API: https://api.dicebear.com/10.x/open-peeps/png
- Style and license: https://www.dicebear.com/styles/open-peeps/
- License overview: https://www.dicebear.com/licenses/
- Original artwork: Open Peeps by Pablo Stanley, CC0 1.0

The assigned `profileImage` asset path is stored on each local demo employee.
The database fills only missing avatar paths, so existing employee details and
login credentials are not changed.
